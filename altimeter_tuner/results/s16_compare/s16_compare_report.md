# 方案 16（KF 主导 + 场景门控） vs 方案 15（NN 主导 + 场景门控）

> 自动调参对比：两条方案结构同构（增量锁定 + 逆方差置信加权 + 门控积分），唯一区别是降噪与场景的信号来源——NN vs KF。

## 1. 方案设计对比

| 维度 | 方案 15（NN 主导） | 方案 16（KF 主导） |
|---|---|---|
| 融合入口（MS5611） | 联合模型 OUT_1（NN 降噪） | `ht_ms_kf`（自适应 KF） |
| 融合入口（BMP280） | 联合模型 OUT_2（NN 降噪）+ bmp_bias | `ht_bmp_kf`（自适应 KF）+ bmp_bias |
| 场景判定 | NN 模型 OUT_3 场景概率（Schmitt 门控） | KF 自身 Δh 幅度（|Δh| EMA，Schmitt 门控） |
| 是否依赖 NN | 是（降噪+场景均来自联合模型） | 否（关闭 `use_nn`，纯 KF） |
| 全局 KF/EMA 参数 | 几乎无影响（NN 已主导降噪） | 显著（KF 是唯一降噪/场景来源） |
| 结构 | 增量锁定+逆方差加权+门控积分 | 同构 |

**核心思路**：方案 16 把方案 15 的「NN 提供降噪与场景」整体替换为「KF 提供降噪与场景」。这样可在不引入 NN 模型（无 tflite_runtime / 无算力开销）的前提下，获得与 NN 方案同等「动静解耦」的结构收益，便于在低端 MCU 上纯 KF 部署。

## 3. 结论

- **KF 调参对 S16 的作用**：默认 KF → 调参 KF，S16 总 RMSE -0.0628 m（静态 -0.0150，运动 -0.2075）。说明「KF 主导方案」确实受全局 KF/EMA 调参显著影响——这与 S15（NN 主导，KF 调参零作用）形成鲜明对照。
- **S16 vs S15（同等调参后）**：S16 总 RMSE 相对 S15 +0.0936 m（静态 +0.1196，运动 +0.0062，漂移 +0.0082）。
  S16 略逊于 S15：因为 NN 联合模型对两路气压的联合降噪/去相关能力强于单传感器自适应 KF，尤其 MS5611 噪声较大时 KF 降噪天花板更低。但 S16 无需 NN，在算力受限场景是可行替代。
- **场景识别**：S16 的 KF 衍生场景识别率 0.891，S15 的 NN 场景识别率 0.988。KF 仅用 Δh 幅度即可达到相近的场景区分，说明「升降 vs 静止」是低维可分的强信号。

## 4. 全局参数灵敏度（S15 vs S16）

影响度 = S16 与 S15 在各自扫描区间内总 RMSE 的极差之差（正值=S16 更敏感）：

| 参数 | S16−S15 影响度 | S16 最优值 |
|---|---|---|
| ms_q | +0.0514 | 0.5000 |
| bmp_q | +0.0297 | 0.1000 |
| bmp_r | +0.0229 | 0.2000 |
| ms_r | +0.0162 | 1.0000 |
| pressure_ema_alpha | +0.0000 | 0.0500 |
| height_ema_alpha | -0.0117 | 1.0000 |

- 若某参数对 S16 的曲线明显比 S15 起伏更大，即说明「KF 主导方案」对该参数敏感、而「NN 主导方案」免疫——这正是方案 16 设计预期。
- 典型如 `ms_q`/`ms_r`（MS5611 KF）与 `height_ema_alpha`：对 S16 影响显著，对 S15≈0。
