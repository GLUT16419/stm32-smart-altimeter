## 4. 关键结论

- **最关键的全局杠杆是 `height_ema_alpha`（高度 EMA 平滑）**，影响度约为次参数 `ms_q` 的 1.7 倍，
  且呈单调：α 越大→输出越跟手（运动 RMSE 降、静态噪声升），α 越小→越平滑（静止更稳、运动滞后）。
  本脚本评分用 0.3 静态 + 0.7 运动（偏运动），故最优落在高位（≈0.85~1.0）。
  **实践建议**：若更看重「静止纹丝不动」，把它降到 0.5~0.6；若更看重运动跟手，保持 0.8+。
- **`ms_q`（MS5611 KF 过程噪声）是第二杠杆**，仅对融合入口含 `ms_kf_out` 的方案
  （S1/2/3/4/5/6/7/8/10/11/13）有效；最优约 0.18~0.39，比默认 0.03 更信任观测（更跟手）。
- **`pressure_ema_alpha` 影响度 = 0（完全冗余）**：气压 EMA 只是高度换算前的中间平滑，
  最终平滑由 `height_ema_alpha` 主导，二者作用重叠。固件可保持默认 0.4，无需调。
- **BMP280 的 KF（Q/R）影响度极小**：因绝大多数方案以 NN 滤波后的 BMP280 气压为主，
  原始 BMP280 KF 几乎不参与融合；保持固件默认值即可。
- 综上：全局 KF/EMA 调参对「总 RMSE」的平均改善约 1cm（融合质量主要由 NN 联合模型决定，
  KF 仅是次要修正）；真正可调且有效的全局旋钮只有 `height_ema_alpha` 与 `ms_q` 两个。
- 灵敏度排名靠前的参数即固件后续重点调优对象；排名靠后的（pressure_ema_alpha、BMP280 KF）
  可固定为默认值，节省调参预算。
